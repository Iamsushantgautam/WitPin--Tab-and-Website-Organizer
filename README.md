# 📌 WitPin - Tab & Website Organizer

**WitPin** is a fast, privacy-first browser extension for Chrome, Edge, Brave, and Vivaldi that lets you pin websites, organize tab groups, and save tab workspaces locally.

Built with **Pure HTML, CSS, and Vanilla JavaScript** — 100% standalone with zero dependencies or build steps.

🌐 **Website**: [https://wittools.vercel.app/witpin](https://wittools.vercel.app/witpin)

---

## 🚀 How to Install & Load

You can load this folder directly into your browser!

1. **Download or Clone the Repository**
   - Download the ZIP or clone this project folder to your computer.
2. **Extract the ZIP file** (if downloaded as `.zip`).
3. **Open Extensions Page in your Browser**
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
   - **Brave / Vivaldi**: `chrome://extensions/`
4. **Enable "Developer mode"**
   - Toggle the **Developer mode** switch in the top-right corner.
5. **Load Unpacked Extension**
   - Click **Load unpacked**.
   - Select the `witPin` folder (containing `manifest.json`).
6. **Done!**
   - Pin **WitPin** to your browser toolbar for quick access.

---

## ⌨️ Keyboard Shortcuts

- `Alt + Shift + P`: Open WitPin Popup
- `Alt + Shift + S`: Save current active tab to WitPin
- `Alt + Shift + G`: Save current window tabs as a workspace

## 📁 Project Structure

- `manifest.json` — Extension configuration (Manifest V3)
- `index.html` & `src/popup/` — Extension popup interface & logic
- `options.html` & `src/options/` — Options page interface & logic
- `src/background/` — Background service worker
- `icons/` — Extension icons
